# slop games

![slop games: Voxel Raid and HELLCAST](social-preview.png)

AI-generated game experiments. Each subdirectory is a standalone project.

- [`voxel-raid/`](voxel-raid/) — voxel extraction shooter (Rust)
- [`doom/`](doom/) — HELLCAST, a raycasting Doom-like (Rust + wgpu)
- [`museum/`](museum/) — The Museum of Human Achievement, a walkable 3D museum (Rust + Bevy)
- [`museum-three/`](museum-three/) — the same museum for the browser (three.js)
- [`monster-race/`](monster-race/) — Monster Race, split-screen kart racing on the backs of colossal beasts (Rust + Bevy)
- [`sudo-sacrifice/`](sudo-sacrifice/) — sudo sacrifice, a Sacrifice-like where coding agents sacrifice old software at their altars to summon subagents (Rust + Bevy)
- [`bogwight/`](bogwight/) — BOGWIGHT, a physics-driven side-scroller where you're the swamp creature stalking the monster hunters who followed you in (Rust + Bevy + Avian)
